# 浏览器级测试

## 日常运行

依赖已存在时直接运行：

```text
pnpm test
pnpm test:e2e
pnpm build
```

`pnpm test:e2e` 使用 Playwright Test，默认执行 39 条场景 × 320/360px 两个项目，共 78 次。Node 需支持 `node:sqlite`（沿用项目的 Node 22.12+ 或更高环境）。浏览器与 Vitest 分开运行。

Windows本机优先使用已安装Chrome，其次Edge，不会安装或升级系统浏览器。其他环境或CI使用Playwright版本配套的Chromium；未安装时先执行：

```text
pnpm test:e2e:install
```

浏览器下载在工作区 `.playwright-browsers/`，已gitignore。Linux CI若还缺系统库，可执行 `pnpm test:e2e:install --with-deps`（需由CI环境提供对应系统包安装权限）。不在测试命令里自动安装浏览器。

可通过 `TODAYCENTS_BROWSER_CHANNEL` 选择Playwright支持的已安装通道，如 `chrome` / `msedge` / `chromium`。`CI` 环境不自动选系统Chrome，默认使用已下载的版本配套Chromium。首次依赖安装仍使用现有pnpm工作区缓存配置。

只执行一个宽度或一个场景：

```text
pnpm test:e2e --project=mobile-360
pnpm test:e2e --grep "yesterday"
```

## 实际覆盖

- 真实支出录入、今天页显示、刷新保留、流水可见，并核对SQLite整数分。
- 随手记自动露出靠后的预填一级和细分。展开后核对两级换行、归档项不出现在选择器及「未分类」排末尾。换方向、收起分类和继续草稿后，核对所选细分及实际入库结果。
- 用不同的收支历史账户检查首次预填、手选账户在各类型之间独立、继续草稿和实际写入。仅改另一类型的账户也能保留草稿，放弃后恢复默认值。
- 随手记连按到第 8 位整数、第 3 位小数，核对上限提示、带负号和千分位的完整金额及保存的整数分。编辑流水和项目预算覆盖「00」部分输入、退格或重开清除提示、首次按键替换已有金额。
- 既有“+ → 昨天”，固定日期下覆盖元旦到上年12月31日，不新增日期浏览功能。
- 先保存今天的支出，再用不同分类和账户补记昨天。核对两笔实际入库的日期及金额，并确认新草稿使用补记的分类和账户，日期仍为今天。
- 流水年月标题打开日历。核对未来日期禁用、无效年份的焦点循环、空月份直达及选择闰日后按组头定位。核对从标记日或空日提示下打开流水后，编辑返回恢复原行及日期反馈。模拟 Android 返回键可取消打开的日历。
- 流水日柱的可访问名称覆盖仅调整、仅转账、支出与收入混合、空日、仅软删除记录和未来日。检查成对转账计为一笔，键盘和点击激活后聚焦日期标题，再按 Tab 进入当天首条流水。
- 保持今天页和随手记打开，推进本地时钟从 12 月 31 日过到 1 月 1 日。检查日期、星期、当日列表、快捷项和日期上限，核对新保存流水的日期。
- 模拟切回页面和 Android 前台事件。已填金额和备注保留，未选日期跟随新一天。明确选择的补记日期在跨日、收起再打开、保存时保持一致。
- 数字键盘显示时触碰随手记日期框一次，核对同一次触碰内调用日期选择器，之后收起键盘。模拟日期区字号放大 1.3 倍，核对日期独占一行、宽度容纳完整年月日、44px 触摸高度。选择过去日期后核对原金额、备注和落库日期。
- 流水长按和触摸拖放。短滑动、原地松手、触摸期间的原生菜单和焦点变化、5 秒撤销窗口及到期后才写入 SQLite。
- 转账从任一腿发起后成对暂存，键盘取消确认恢复焦点，换页取消待删除请求并在回到原页面时提示。到期后软删除两条腿。
- 从今天的转出和流水的转入打开同一笔转账。核对锁定日期、修改前后余额、阻止同账户、模拟部分更新失败时整组回滚、重试原位返回，以及保留原归档账户只改备注。两条实际流水保持原标识、日期、分组和出入统计口径。
- 推进待删除时钟到第 5 秒，核对剩余时间、撤销入口及合计。模拟切后台再返回时提示取消。暂停软删除写入验证合计仍计入原流水，提交成功后更新。
- 保持网页可见，模拟 Android 在短时间内切出再返回。只送恢复通知时立即取消，通知延迟到计时结束之后时仍阻止写入。旧通知到达时，仍处于同一次前台的新请求可在满 5 秒后正常提交。
- 使用 SQLite 触发器模拟删除写入失败，确认列表恢复显示，数据库没有写入删除时间。
- 浏览器直接下载月报，解析工作簿，核对文件名、「支出汇总」表名和「支出总计」行名。核对导出按钮下的结果显示实际下载文件名，且没有原生目录或缓存入口。
- 一月末保存账户额度 100，二月初改为 200 后核对一月仍按 100 对照支出。清空二月额度并刷新，再次核对一月额度与支出。
- 从当前年一月切到上一年十二月，再切年报。核对上一年的标题、支出合计、年报文件名以及文件中的「支出汇总」和「支出总计」。翻到更早一年后点已选的「年」，核对年份保留。切回「月」恢复十二月，再切年报重新进入十二月所属年份。
- 打开月报和年报的分类排行明细，核对一级支出、归档细分支出和未分类两种记录都进入对应合计。检查长列表滚动时合计及关闭按钮的位置，模拟 Android 返回、点关闭和 Escape 都将焦点还给对应排行。
- 录入一笔转账并保留一条软删除支出。核对流水显示 1 笔，清除确认、备份摘要及导入确认显示 3 行流水记录。下载时核对实际文件名，次日导回同一文件。刷新后检查确认备份记录、恢复时间、源文件生成时间、转账的两行以及支出的软删除状态。
- 依次选中同名且流水记录行数相同、账期不同的合成备份。覆盖确认显示各自的流水日期和未归档账户数，初始焦点在「取消」，取消后核对本机流水。
- 从今天列表中段、跨年的历史月份和项目详情打开编辑。用页面返回、模拟 Android 返回回调及保存验证来源、原月份、行焦点和滚动位置。取消项目关联并保存后，原项目恢复滚动位置。
- 打开只有一笔的项目查看预览，再打开含历史报销的归档项目的全部流水。核对五笔预览、跨年日期、支出收入及软删隔离，验证历史流水编辑返回、保存备注、取消项目归属和系统返回。
- 在两个一级分类下各建同名细分。打开历史月流水核对原分类路径，切换父级后改选同名细分，检查 SQLite 实际分类 ID 和原行焦点。改已有归档细分的流水备注时保留原分类，点「不细分」才改至一级。
- 同时修改支出流水的备注和固定支出开关。直接返回后两项仍为原值。模拟开关写入失败，检查账本原值和表单草稿。重试后两项一起生效，重新编辑关闭开关也可保存。
- 固定支出页打开一月已标记的记录。二月预计日期已过且还没记账时，分列本月已记 0.00、预计月额 45.00，显示「待核对」和一月实记日。录入二月匹配支出后重新打开清单，核对本月已记、最新预计月额和新预计日期。
- 从固定支出的「查看来源流水」打开一月实记，模拟 Android 返回恢复原行焦点。二月有匹配支出时打开二月实记，保存备注后回到原行。软删除二月流水后再次打开清单，入口和预计月额回到一月实记。
- 确认固定支出建议后撤销，核对原手工标记。停用后核对合计归零、候选隐藏、焦点和触控高度，刷新后从「已停用」恢复两项合计。点「不是」后从「已忽略建议」恢复识别，核对建议回归和原流水标记。
- 随手记的收起、遮罩、模拟 Android 返回和去流水覆盖草稿选择。复开核对金额、分类、账户、标签、项目、日期和备注。转账第二条腿写入失败后保留两侧选择，重试成功后打开新表单。已归档账户会拦截保存，整库清除后清掉草稿。
- 只保留一个可用账户，切到转账立即提示并禁用保存。分别直接进入新增表单、打开已归档列表。取消后原草稿仍在，新增或恢复第二个账户后可选两侧。恢复路径核对两条转账记录的共同分组、金额、补记日期和备注。
- 清除确认的初始安全焦点、Tab循环、取消/Escape/遮罩关闭和焦点返回；不执行实际清除。
- 保存等待时Escape与遮罩不能离开、收起按钮禁用；去流水链接目前检查aria-disabled，未宣称实际点击该链接。
- 写入失败后报错、事务回滚、草稿保留与重试成功。
- 无账户时新增账户，返回随手记保留金额/备注，实际保存成功。
- 账户页顶部显示「账户余额」及未归档账户的合计口径。显示有余额的已归档账户后，合计仍排除该笔余额。对账预览账面余额、实际余额和预计差额。留空拒绝提交，余额一致不写流水，明确输入零只写一笔调整。检查账户余额、SQLite 流水和月度收支。
- 从账户对账后打开调整流水，核对原账户、日期和差额的只读显示。保存备注并检查 SQLite 中该笔调整的归属、金额和日期。
- 在 320/360px 以触控长按拖动账户，覆盖取消、顶部插入、普通点按展开、键盘下移和焦点保留。刷新后核对顺序，并检查随手记支出、收入及转账两侧的账户顺序。长列表覆盖靠近屏幕边缘连续滚动和拖至末尾插入。
- 在 320/360px 验证分类长按拖动，覆盖二级分类越组松手、同父级插入、一级分类带细分整组插入、菜单上移、独立的收入排序与刷新保序。拖动时检查新增按钮和提示让开插入线，取消后新增按钮恢复。检查系统及归档项、随手记和编辑流水内的顺序，以及原流水分类 ID。
- 用合成数据删除零历史项目和账户，覆盖进行中与已归档项目、未归档与已归档账户、取消焦点及确认后余额变化。已软删除流水和旧模板仍阻止删除，确认面板打开后新增项目引用也会在提交时拦截。
- 项目新建、改名与预算键盘保存，名称触控高度、滚动及横向溢出。
- 设置 A 的三块布局、组内入口顺序、清除区间距和窄屏触控高度，确认清除按钮不被底栏遮挡。

浏览器默认使用上海时区 2026-01-01 中午，跨日和固定支出场景会另设日期。删除和跨午夜场景用浏览器时钟推进计时器。金额、账户和备注均为合成数据。页面 JS 异常使测试失败，失败截图和 trace 可在 `.superpowers/e2e/results/` 查看，下一轮会自动清理旧结果。临时目录、编译缓存和测试专用构建位于 `.superpowers/e2e/`。

## 数据层和离线边界

测试从真实 `index.html` / `src/main.tsx` 构建，运行实际App、路由、hooks、迁移、seed与仓储。只有测试构建将Android专属 `capacitorDriver` 替换为 `tests/browser/driver.ts`。该适配器使用生产SerialDb与TransactionRunner，把SQL发给仅绑定127.0.0.1:4179的测试服务，由Node真实内存SQLite执行。

每个新浏览器context产生独立sessionStorage UUID和数据库；同一测试内reload保留该库。测试开始断言空今天页，服务退出销毁全部内存库。读写失败通过Playwright路由拦截注入，不修改生产仓储。服务禁止复用已有端口，主动关闭需当前运行的临时token，避免Windows进程树回收等待。

测试别名由 `tests/browser/server.mjs` 的独立构建配置启用，测试 SQL 服务和测试适配器只在浏览器测试构建中使用。

它不验证Capacitor实际桥接、Android权限页、系统分享、原生返回键或软键盘遮挡；`page.keyboard` 验证的是DOM键盘事件与焦点。图表标签、系统分享相关的报表路径及全部管理路径尚未纳入这批浏览器用例。真机验证入口仍见 `交接/真机调试.md`。
